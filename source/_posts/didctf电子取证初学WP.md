提取内存镜像中的USB设备信息，给出该USB设备的最后连接北京时间？ [答案格式：2000-01-11 00:00:00]
这里真正像外接 U 盘的设备是：

```
VID_0781&PID_558CSerial Number: 32313131374D343032343132[2023-06-20 17:01:25 UTC]
```

其中：

```
VID_0781
```

通常对应 **SanDisk 闪迪设备**，`PID_558C` 是该 USB 设备的产品 ID。前面的 `ROOT_HUB`、`ROOT_HUB20`、`VID_0E0F` 更像是 USB 控制器、虚拟机相关设备，不是题目要找的外接 USB 存储设备。
所以最后连接时间取：2023-06-20 17:01:25 UTC
